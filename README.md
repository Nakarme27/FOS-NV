# OpenNV
This is a Android port of OpenNV, with NativeAOT, Mobile render and fixes to mobile devices.
# Thanks
Esse projeto só seria possível por Nikami e Nick Bryson, sem vocês nada disso seria possível.
# Future
This is just a simple port of the flat PC version to Android, with initial support only for New Vegas; in the future, I plan to switch from Godot to Google Filament with pure Jolt Physics, using C++ and Python instead of C# and GDScript.
This include a comunity suporte to make a new version of "OpenMW" with advanced physics and Vulkan Renderer and future port of Skyrim, Oblivion and Fallout 4, I'm counting on your help.
